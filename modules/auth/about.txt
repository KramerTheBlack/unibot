По умолчанию - есть один администратор. Его данные авторизации в web-консоли и чат-ботах хранятся в подпапке secrets корневой папки проекта в файле auth.
Дефолтное значение:
username: unibotadmin
password: tellmepass

Остальные пользователи - без прав.

Первый админ может включить разграничение доступа (при этом задаётся место хранения информации - файл SQLite в папке secrets, либо хранилище данных, подключаемое через модуль datastore), создав группы с административными привилегиями, привилегиями покупателей (в базе хранятся идентификаторы пользователей для использования их при работе в функциональных модулях), и без привилегий (каждый сеанс работы с пользователем начинается без исторического контекста).

Так же модуль имеет функцию регистрации (анонимные пользователи соглашаются на обработку данных, регистрируются и переводятся в группу покупателей).
Зарегистрированных пользователей-покупателей администратор может перевести в группу администраторов.

Вся работа администраторов по настройке авторизации и управлению группами выполняется через веб-консоль или из чатов после переключения в административный режим.
Операции регистрации пользователей выполняются специальными командами из чатов.

В модуль menu от модуля auth включаются пункты "Зарегистрироваться" (для регистрации анонимных пользователей в качестве покупателей) и "Управлять" - для переключения в режим Администратора.

Хранение данных авторизации предполагается: Для каждого пользователя есть ID (привязка к номеру телефона), персональная информация (ФИО, почта и .т.п.), и данные ою используемых чатов (вк, макс, телеграм…)
