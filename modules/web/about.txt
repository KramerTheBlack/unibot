Веб-интерфейс администрирования.
Доступна только тем, у кого роль администратора.
Авторизация для дефолтного админа по логину и паролю, для остальных - через номер телефона и 2FA

Главная страница содержит информацию о владельце и назначении бота (из файла modules/web/module.info)
- Страница со списком подключенных можудей (ссылкой можно перейти на страницу настройки каждого)
- Страница со списком пользователей и групп. Там можно упавлять администраторами и клиентами.
- Страница настройки меню
- Странца настройки работы с LLM (задаётся апи, токен, дополнительные параметры запроса, формат ответа или выполняемых ботом действий).

По умолчанию интерфейс поднимается на локальном IP-адресе и порту 8080 по протоколу http. Но доступны настройки для работы из интернета по протоколу https, с указанием адреса URL и сопоставляемого ssl-сертификата.

Для модуля должен быть доступен конфигурационный файл, позволяющий настроить цветовую схему, используемые иконки и картинки, стили и шрифты.
